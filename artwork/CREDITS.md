# Artwork credits

`logo.svg`, `autostorager-1x1.svg` and `marketplace.png` combine two icons from
SVG Repo. `marketplace.png` is the square upload for the marketplace listing;
`logo.svg` is the mark beside the README title.

| Icon | Source | Licence | Author |
| --- | --- | --- | --- |
| file-horizontal | https://www.svgrepo.com/svg/532773/file-horizontal | [CC Attribution 4.0](https://creativecommons.org/licenses/by/4.0/) | Dazzle UI |
| hand-holding | https://www.svgrepo.com/svg/473219/hand-holding | [MIT](https://www.svgrepo.com/page/licensing/#MIT) | jtblabs |

The file-horizontal icon is CC Attribution, so Dazzle UI is named in the
image's credit line and here. The hand-holding icon is MIT; jtblabs is named
anyway. Both icons were recoloured and combined, which the credit line says.
