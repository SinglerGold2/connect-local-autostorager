# Artwork credits

`logo.svg`, `logo.png`, `autostorager-1x1.svg`, `marketplace.png` and
`autostorager_github.svg` combine two icons from SVG Repo.
`autostorager_github.svg` is the GitHub banner and the README header;
`marketplace.png` is the 1:1 upload for the marketplace listing; `logo.svg`
and `logo.png` are the mark alone.

| hand-holding | https://www.svgrepo.com/svg/473219/hand-holding | [MIT](https://www.svgrepo.com/page/licensing/#MIT) | jtblabs |

The file-horizontal icon is CC Attribution, so Dazzle UI is named in the
image's credit line and here. The hand-holding icon is MIT; jtblabs is named
anyway. Both icons were recoloured and combined, which the credit line says.
